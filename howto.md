How to use it
1. Extract the ZIP into your project directory.
2. Open README.md.
3. Read WHAT_TO_UNDERSTAND.md.
4. Start tracking work using task_tracker.csv.
5. Use AI_PROMPTS.md when studying, implementing or analysing.
6. Record every experiment using EXPERIMENT_PLAN.md.
7. Follow ANALYSIS_PLAYBOOK.md before interpreting any results.
